# Вход в Spender

Перед работой прочитай [общие правила](CLAUDE.md), затем
[handoff](docs/handoff.md) и [backlog](docs/backlog.md); проверь HEAD,
`git status` и diff. Это существующее macOS-приложение, не новый проект.

Есть два последовательных режима: **Desktop** и **терминальный Herdr**.
Их назначения моделей, ответственность и переход описаны только в
[CLAUDE.md — Режимы работы](CLAUDE.md#режимы-работы).
Этот файл — вход и указатели, а не вторая копия общих правил.

- Назначение, структура исходников, запуск и тесты: [README.md](README.md).
- При задаче по API провайдера: соответствующий клиент в
  `LLMSpendMonitor/Providers/`, его тесты и [исследования API](docs/research/).
  Актуальность внешнего контракта проверяй по официальной документации.
- При UI-задаче: `LLMSpendMonitor/UI/`, `LLMSpendMonitor/Features/`
  и `LLMSpendMonitorUITests/`; интерфейс здесь нативный SwiftUI.
- Планы в `docs/plans/` — контекст конкретной задачи, не автоматически
  действующая очередь. Приоритеты и разрешённый объём берутся из backlog.
